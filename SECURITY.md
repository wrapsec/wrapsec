# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities by emailing **security@wrapsec.com**. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or proof-of-concept code
- Affected versions and components
- Any suggested mitigations if known

We aim to acknowledge reports within 2 business days and provide a resolution timeline within 7 days. We will keep you informed as the issue is investigated and resolved.

Responsible disclosure is appreciated. We ask that you allow reasonable time to address the issue before public disclosure.
