# The MCP protocol SDK. Optional at RUNTIME -- the gateway neither imports nor
# requires it -- but the protocol tests drive the adapter over a real stdio

# requirements-mcp.txt.
#
# The client SDK the adapter wraps is deliberately NOT listed here. This file is
# installed from a stage that has copied requirements*.txt and nothing else, so a
# path requirement pointing into the source tree fails the image build; the SDK
# is installed editable after the source arrives, for every build stage.
